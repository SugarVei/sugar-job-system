# Sugar 自定义配色

从顶栏配色圆点右侧的小调色盘进入工作台。图标悬停或键盘聚焦时显示“自己设计颜色”。“随机换一组”用于探索；“生成配色”应用当前五色并返回进入前的页面。工作台保留 Sugar 标志、中文操作与已确认的紧凑布局。

## 分配规则

- 保留用户五色的色相，在 OKLCH 中统一调整明度和色度；超出 sRGB 的颜色只降低色度，保持明度和色相。
- 页面底色使用最高色度颜色的轻微染色，明度 0.977；中性容器明度 0.991，避免大面积强色。
- 五组卡片底色明度交替为 0.943、0.950，色度上限 0.037；卡片文字明度 0.345，色度上限 0.075。五色全部参与，不因原始颜色过暗或过亮而丢弃。
- 固定区域按 0–4 循环分配；记录卡片按记录 ID 的稳定散列分配，整体近似均匀，筛选、翻页和排序不改变同一记录的颜色。
- 主操作取最高色度颜色，降低明度直到与白字对比度至少 4.6:1。图表使用五组更清晰的强调色；成功、警告、失败等业务状态继续保持原有语义。
- 五色相同或全黑、全白仍能生成中性主题。测试覆盖 105 组极端及随机配色，检查卡片文字 7:1、普通文字及按钮 4.5:1 的对比度。

## 保存与返回

主题继续沿用现有浏览器本地偏好：`sugar_theme` 记录当前主题，`sugar.custom-palette.v1` 保存五色，`sugar.palette.studio-draft.v1` 保存工作台草稿。应用后关闭自动轮换；现有预设与已保存自定义圆点均可再次选择。此功能不写入账户数据库。

工作台通过 `#/palette-studio` 显示独立 iframe，原页面继续挂载，保留表单、搜索、筛选和滚动位置。刷新工作台后仍可应用或返回。父页面仅接受同源且来自该 iframe 的消息，并验证五个完整 HEX 值。

主要实现：`src/lib/customPalette.ts`（主题规则）、`src/contexts/ThemeContext.tsx`（保存与主题）、`src/components/PaletteStudio.tsx`（应用与返回）、`public/palette-studio.html`（工作台）。
