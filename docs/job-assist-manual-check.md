# 求职辅助 MVP 手动验收

## 准备

1. 按文件名顺序在 Supabase 应用 `supabase/migrations/20260812052749_job_assist_mvp.sql` 和 `supabase/migrations/20260812065000_job_assist_foreign_key_indexes.sql`。
2. 准备测试账号、可用的 AI API Key，以及一份不含敏感字段的 PDF 或 DOCX 测试简历。
3. 运行 `npm run dev`，登录后进入“简历库”。

不要使用真实身份证号、银行卡号、验证码、密码、健康/犯罪/征信信息或电子签名做测试。

## 主流程

1. 新建一张简历卡片并上传简历本体，确认原有上传、下载、删除和“AI 生成面试稿件”仍可使用。
2. 点击“求职辅助”，选择校招或社招，确认进入简历画像步骤。
3. 分析简历，检查画像、优势、短板和 2～3 个推荐方向；输入一条事实更正并重新分析，再确认画像。
4. 填写目标城市、方向和路线专属偏好，把每天推荐上限设为 1～20 内的值并保存。
5. 粘贴包含岗位职责和任职要求的完整 JD，检查硬门槛、匹配分、证据覆盖率、三类缺口和下一步建议。
6. 生成定制建议与文字草稿，确认信息缺口和能力缺口没有被写成个人经历；保存为新简历版本，并在简历库看到新卡片和可展开的文字草稿。
7. 在“写入关联投递”选择“意向 / 待投递”或用户真实确认的阶段并保存，确认当前简历卡片的“关联投递”数量增加，投递记录页可见同一条数据。
8. 开始 3 题文字模拟面试。每次只回答一题，检查五维评分、改进建议、重答/继续流程；完成后确认显示平均分。

## 空态、失败和安全边界

- 没有简历文件时点击“求职辅助”，应看到“请先上传简历本体”，不能出现未捕获异常。
- 未配置 AI Key、简历解析失败、JD 过短或 Supabase migration 未安装时，应显示可读错误，并允许回到对应按钮重试。
- “网申草稿”显示为即将上线且不可点击。
- 页面应持续显示：不自动最终提交、不处理敏感字段、不生成/换脸证件照。
- 检查 `job_assist_interview_questions`：只有题目、分数、标签和简短摘要，没有回答原文或完整润色答案字段。
