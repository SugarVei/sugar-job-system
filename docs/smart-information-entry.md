# 智能信息录入

该模块介绍 Sugar 求职助手的安装、账号关联、AI 配置和岗位同步方法。入口位于网站原有侧边栏及移动端「更多」中。侧边栏保持平铺排列，不显示分组小标题或账号副标题。

- 直接入口：`#/smart-information-entry`，兼容 `#/smart-input`。
- 四个页签：功能概览、安装与配置、操作演示、常见问题。
- 下载：`public/downloads/Sugar-Job-Assistant-2.0.1.zip`，540524 字节。
- SHA256：`dc65897977a40961ac67e561b78b0ed6578e3837b153f05364be162101347bab`。
- 安装教程分别提供 Chrome / Edge 地址，说明先解压、加载包含 manifest.json 的目录、登录网站同一账号，再配置个人 AI 与网站授权。
- 操作演示使用虚构岗位，仅保存在当前页面的 React 状态中。选择、搜索、保存、去重、查看记录、详情和重置均不调用真实投递写入接口。
- 常见问题支持分类、关键词搜索、展开及空结果恢复。

页面按需加载，样式限定于 `.smart-input-page`，主题颜色使用网站现有 `--sugar-*` 变量。字体与许可证均随项目本地提供。既有手工添加投递功能保持可用。
