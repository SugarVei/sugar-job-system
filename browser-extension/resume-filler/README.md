# Sugar 智能填表助手 1.2.0

基于用户提供的 AI-Resume-Form-Filling-Assistant 1.1.1 修改，原许可证 GPL-3.0 见 LICENSE。扩展源码完整随包提供。修改日期：2026-09-16。

## 安装
1. 解压 ZIP，保留 Sugar-Resume-Assistant 文件夹。
2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
3. 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 在浏览器扩展菜单中固定 Sugar 智能填表助手，打开招聘表单后点击图标。
5. 点击右上角 API 设置，选择厂商、输入该厂商 API Key，保存后自动启用。通义千问使用北京区域密钥，Kimi 使用中国站密钥。
6. 在“标准简历”中打开简历配置页，填写自己的资料并保存。
7. 回到招聘页面点击“开始填充”，完成后核对内容，手动提交。

## 数据与使用
首次安装没有个人简历或 API Key。资料和密钥保存在当前浏览器；无需网站配对，不会自动同步网站资料。使用 AI 映射时会发送页面字段与简历字段摘要，使用 AI 导入时会发送原始简历给所选厂商。请仅导入你愿意交给该厂商处理的信息。不会自动提交表单。
更新时替换扩展文件并在扩展管理页点击重新加载；不要先卸载，否则可能丢失本地资料。
