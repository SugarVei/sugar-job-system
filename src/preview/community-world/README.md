# Sugar 求职小镇预览

入口：`/world-preview.html`。在仓库根目录执行 `npm install`，随后执行 `npm run dev -- --host 127.0.0.1 --port 6088 --strictPort`。

这是以 cubicles.lol 实际浏览器场景为视觉参照的独立 Three.js 预览：奶油色开放隔间、彩色门牌和地板边线、桌椅电脑、方块人物、正交斜俯视镜头。模型由本项目代码生成，不依赖外部模型文件、第三方服务凭据或原站私有代码。

人工岛四面环海，含沙滩、环岛步道、两座码头与九宫格街道。四个住宅区各有 5×5 间房，共 100 间；中央广场为 40×40，与完整住宅区同大。另有一座公园、一座游乐场，以及足球、篮球、羽毛球场各一座。游乐场包含摩天轮、秋千、滑梯的场景模型。

默认左键/单指自由平移，右键旋转当前视野，滚轮向鼠标指向的位置缩放，双指缩放/旋转；顶部可切换左键旋转模式。平移不再限制在岛心周围。点击空地自动寻路，WASD / 方向键或手机方向盘移动。可切换第一人称，拖动环顾，空格跳跃。房间统一为三面墙、正面开口，并同步增加右墙碰撞检测。房间支持标签搜索、收藏、领取、名称/介绍/标签/配色/地板编辑及 6 类家具的添加、拖动、旋转、移除，每间最多 12 件装饰。

“玩乐出行”提供快速前往入口；靠近后按 F 或点击场景设施进入，F/退出按钮安全离开，支持乘坐时切换第一人称。手机直接点“开始体验”和动作按钮：

- 摩天轮：人物跟随座舱转动，座舱保持水平。
- 秋千：空格加力，人物跟随摆动。
- 滑梯：爬上平台、沿滑道下滑，完成后自动退出。
- 足球：方向键带球，空格射门，球门判定计分；羽毛球：对练、定时挥拍与回球；篮球：在绿色区间出手，抛物线投篮并计分。
- 出租车：恰好 5 辆，沿内外环街道自动巡游，靠近点击或 F 上下车；每车 4 个乘客座位，第五位拒绝，同一乘客重复上车不占额外座位。当前只有本机人物，尚未实现真实多人共享车辆。
- 游艇：1 艘可驾驶游艇、3 艘巡游帆船。W/S 调速、A/D 转向；船体移动路径逐段校验，禁止进入陆地/码头、穿过其他船只或超出海域；退出时返回码头。
- 飞机：2 架空中巡游飞机，登机点可驾驶其中一架。高度固定 38 米，水平范围 x/z ±210 米，到边界自动转向岛屿；退出返回地面登机点。飞行和航海不是现实物理模拟。

点击广场中的三维公告牌或“世界公告栏”，可以按 Offer 分享、面经交流、求职求助、公司评价、岛上闲聊分类浏览、搜索和发布。支持最新/热门排序、帖子赞同、评论点赞、1–5 星信息评价、楼中楼定向回复、删除自己的评论。删除父评论会同时移除其楼中楼。评分汇总明确标为本机评价。示例帖子明确标记为示例，真实录用信息没有被虚构。此预览最多保存 100 篇帖子，每篇最多 50 条回复。

房间和收藏存储在 `localStorage['sugar-community-world:v2']`，兼容读取上一版 v1 房间并迁入新岛第一间空房；公告栏使用 `sugar-island-board:v1`。同一浏览器同一站点刷新后恢复。访客身份和邻居均为预览示例，无真实多人在线、云端同步或正式账户关联；发布帖子仅写入本机，并没有向其他用户发送。清理浏览器数据或更换主机/端口后不会共享存档。保存失败时保留编辑内容并明确提示。

原站没有公开地图总面积，本版是小规模首期人工岛，并非声称已量得原站的精确十分之一。

正式入口为 `/#/community-world`，保留已有登录鉴权和 AppLayout，将原地图校招导航替换为求职小镇；仍兼容已保存的 `capitalMap` 页面标识。独立体验入口 `/world-preview.html` 同时保留。未修改 Supabase 数据；账号归属、房间占用冲突校验、数据库访问权限和多人同步仍需后续接入。

南北栈桥已按实际 T 形桥面加入人物碰撞和寻路区域，岸边、桥身与桥头连续可走，侧边和尽头保留防落海边界。游艇互动点设在南侧桥头，下船也返回桥头。`walkableGround.test.ts` 覆盖两侧桥面通行与边缘限制。

扩建应保留已有房间 ID 和世界坐标，通过新的街区 ID 追加地块，避免因重新计算中心点而搬动现有房间。本版地块与渲染器分离，便于改为按街区加载。

渲染器按材质合并静态街区，编辑中的单间保留可拾取家具。动态世界限频到 30 帧，窗口隐藏时跳过渲染，限制像素比，移动物体不写入静态阴影缓存以避免残影；卸载时释放场景、事件和 GPU 资源。互动状态降低更新频率，并只在变化时更新 React 状态。房间编辑不会把 Three.js 引入原来的主应用入口。

构建：`npm run build`（同时输出原应用和独立预览）。`npm test` 包含栈桥回归测试。推送 main 后由现有 Vercel Git 集成发布。
