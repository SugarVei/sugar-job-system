# Sugar 求职小镇

正式入口 `/#/community-world`，保留登录和 AppLayout；独立入口 `/world-preview.html` 读取同站点登录会话，未登录时为本机访客体验。

## 多人社区

- 使用现有 Supabase Auth；不共享简历、投递信息或用户邮箱。
- 100 间可领取的房间，每个账号一间，数据库主键和账号唯一约束解决并发冲突。示例邻居只在访客模式出现。原本机房间可在编辑器中选择导入，保存后才发布。
- `community_rooms` 保存房间布置；`community_posts/comments/reactions` 保存帖子、楼中楼、评分和点赞。RLS 限制写入本人记录，登录用户可读社区；匿名访问被拒绝。聚合视图使用 `security_invoker`。
- 公告栏每批 50 篇/条，按需加载更多；实时变化触发合并刷新，30 秒轮询兜底。收藏仍为本机偏好。
- 私有 Realtime 频道使用 Presence 维护成员，Broadcast 最多 10 Hz 发送变化的运动状态，静止时每 2 秒一次。远端位置插值，最多渲染 64 个远端人物；运动更新不经过 React state。入站数据有限值及范围校验，持久状态只信任数据库。
- `community_seats` 与 `community_acquire_seat` 原子分配座位：5 辆出租车每辆 4 席、摩天轮 8 席，其余设施每项 1 个操作者。球类为共享场景中的轮流体验/练习机玩法，不是多人竞技对战。
- 每个账号只能占用一个项目；座位绑定标签页 session，25 秒续租、90 秒失联释放，正常退出立即释放。驾驶状态由持有租约的客户端广播，服务端校验占用；不是服务端逐帧物理模拟。
- `community_clock` 校准巡游时钟；人物、驾驶的游艇/飞机与运动物件同步。出租车、摩天轮及巡游物体按共同时间运行。
- 断线保留房间编辑内容，禁止保存失败时假报成功，安全退出当前项目，重连刷新持久数据和成员。

## 场景与操作

人工岛四面环海，4 个 5×5 住宅区、中央广场、公园、足球/篮球/羽毛球场及游乐场。三面墙房间支持 6 类家具。南北 T 形栈桥可连续通行，游艇入口和下船点在南侧桥头。

拖动平移、右键旋转、滚轮向鼠标缩放，支持第一人称；WASD/方向盘移动，F 互动和退出，空格跳跃或执行项目动作。船仅在海上并避让其他船，飞机固定 38 米、水平范围 ±210 米。室内编辑、车辆和游乐玩法保持原有操作。

## 渲染与验证

房间文字共用 atlas，纯色静态模型使用顶点颜色合批，住宅按街区裁剪；固定环境不重复计算矩阵。海岸 18 层透明面合成一张纹理，面板不再实时模糊背景。静态阴影缓存、像素比自适应、隐藏页暂停渲染；动画跟随显示器帧调度，状态变化才更新 HUD。A* 使用二叉堆与碰撞缓存，避免长路径反复排序和碰撞查询。

`npm run build` 构建正式页与独立入口；`npm test` 包含栈桥、寻路和网络输入回归。数据库版本见`community_*` migrations。私钥不得放进 Vite 环境变量；只使用已有公开客户端 key 和用户会话。

2026-09-30 的相同桌面 Chrome / 1440×900 访客场景对比：全景 26→53 FPS、417→79 draw calls；近景 26→55 FPS、159→28 draw calls；纹理 121→23。结果来自同机短时采样，不代表所有设备的保证帧率。双独立真实测试账号验证了位置、房间、帖子/回复/点赞、游艇占用与释放；后端并发验证了出租车四席上限和跨账号权限。
