# 小糖豆 · 大象宝宝与 AI 陪伴

2026-09-22：默认宠物改为用户提供视频中的大象宝宝。`ElephantPet.tsx` 将原状态机映射到走动、抬鼻打招呼、甩鼻子、坐下和睡觉片段；交互玩球继续使用状态机的小球，避免视频中的足球重复出现。`ElephantVideo.tsx` 只清除连接画面边界的暗背景，并在轮廓一像素内去黑边，保持身体原色。视频静音、切到后台暂停、隐藏或弹窗遮挡暂停；减少动态效果偏好下展示静止帧。`/pet/elephant-poster.png` 是同一渲染器输出的透明视频帧，用于聊天头像与加载回退。

原聊天菜单、流式回复、停止、重试、按当前账户读取的 AI 设置保持不变；对话人设、欢迎语、菜单、气泡和公告文案对应大象形象。原公告的绝对 48 小时时间窗保持不变。`/elephant-preview.html` 为本地形象预览，生产应用通过原 `index.html` 挂载宠物；不发布预览页为独立业务入口。

基于 Sugar 现有 React / TypeScript / Vite 实现，无新增运行依赖、无声音。动画和陪玩不需要 AI；登录后的「和我聊聊」仅在用户主动发送时使用其「AI 设置」中当前服务商的 API Key。

## 运行与体验

在项目目录执行 `npm run dev -- --host 127.0.0.1 --port 4177 --strictPort`。

- `http://127.0.0.1:4177/pet-preview.html`：无需登录的个人简历演示场景，所有项目内容均为示例。
- `http://127.0.0.1:4177/`：原网站入口，宠物已挂在登录后的应用布局旁。
- 预览页右侧（手机为下方）的「动作预览」可切换开心、挥手、爬行、睡觉，支持暂停/继续和从头重播；这是独立演示，不会改变浮动宠物的状态。
- 单击萌娃开心；连续 2 秒内点 5 次生气、跑开。
- 在头部悬停 1 秒触发摸头。鼠标靠近会好奇，附近快速移动会追逐。
- 拖动萌娃再松手会落地；触屏使用同样的 Pointer Events。
- 右键、`Shift+F10` 或 `···` 打开菜单；方向键选项、Escape 关闭。
- 陪它玩生成可拖动/抛出的小球；接球奖励心情和亲密度。小球逃得太远时会在 25 秒后结束。
- 45 秒无输入后打哈欠并入睡；鼠标、按键、滚动会唤醒。睡觉菜单可立即体验。
- 菜单隐藏后保留召回按钮；隐藏状态、心情、精力、亲密度本地持久化。
- 每 20–60 秒随机事件：坐下、伸懒腰、好奇、边缘探头、靠近可见卡片并轻触。不会自动点击链接或按钮。
- `prefers-reduced-motion` 下停止自动移动/跳跃；点击、菜单、手动拖动仍可用。球可以手动送到脚边。

## 文件与配置

`src/App.tsx` 在按用户 ID 隔离的 `ApiKeysProvider` 中挂载 `<WebPetCompanion />`，`AppLayout` 内容区上方显示限时公告；共享 AI 流客户端增加可选取消信号，保持其他调用兼容。预览入口与页面位于 `pet-preview.html` 和 `src/preview/`，默认生产构建只构建原 `index.html`。

## AI 聊天与公告

- 宠物菜单「和我聊聊」或公告「认识小糖豆」打开原生模态对话框；支持键盘焦点循环、Escape、手机布局、失败重试与停止回复。
- 复用 `/api/ai-chat`；仅发送固定陪伴提示词、最近 12 条聊天和本次用户输入（最多 2000 字）。不会自动读取简历、调用其他账户密钥或使用系统默认 Key。
- 未配置时直接引导现有「AI 设置」。聊天只存在本次弹窗内存，关闭/登出/切换用户时清空并取消请求；不向本地存储或数据库保存聊天内容。
- 语气温柔、可爱、治愈，明确 AI 身份，不声称医疗能力、不制造排他依赖。第三方服务商自行计费，界面提醒避免发送敏感信息。
- 公告绝对起止时间位于 `petChatConfig.ts`，恰好 48 小时，自动到期，刷新或后续重新部署不会延期；关闭记录按账户隔离。
- 合成流响应验证不等同于已验证真实服务商密钥、余额或模型对话效果。

- `WebPet.tsx`：body portal、React 生命周期、Pointer Events、可访问菜单。
- `PetSprite.tsx` / `PetBubble.tsx` / `PetMenu.tsx`：独立的显示层。
- `spriteAnimations.ts`：三组透明图集、逐帧时长、脚底对齐、统一比例、一次性入睡序列和睡眠尾段循环。
- `core/stateMachine.ts`：明确状态、优先级和单一行为截止时间。
- `core/movementEngine.ts`：加减速移动、方向、边界、取消。
- `core/petController.ts`：rAF 调度、鼠标速度、低频元素缓存、睡眠、抛球、属性持久化、事件清理。
- `petConfig.ts`：尺寸、速度、感知半径、等待时间、睡眠阈值、随机事件间隔、素材映射和 `DEBUG_PET`。
- `WebPet.css`：浮层层级 30、伪 3D 形变、菜单与移动适配。普通内容可穿透，原模态层级为 100。
- `public/pet/baby.png`：内置图像工具基于用户参考图生成的透明 PNG。提示词要点：保留同一萌娃、棕色卷发和大眼睛、淡蓝熊图案连体衣、全身、去掉背景和地面，保留透明 alpha。原始参考未修改。

## 当前视觉边界与升级

本版增加了一组 **24 张连续开心姿势** `public/pet/atlases/happy-smooth.png`，保留原有三组 6 帧透明 PNG。开心使用连续的拍手、小跳跃片段，挥手独立成段，避免抬手到拍手的大跨度变形。移动状态映射为爬行动画，追逐和跑开使用更快的节奏。坐下、拖动、受惊也有独立姿势映射。

这是 3D 风格的 **2D 逐帧动画**，不是骨骼动画，也不具备任意角度的真实 3D 旋转；素材没有完整步行、愤怒脸部序列，相关状态仍使用现有姿势和轻微位移表达。

图集由内置图像工具基于用户的三张动作参考整理生成，保留原参考不修改。素材保存在 `public/pet/atlases/happy.png`、`crawl.png`、`sleep.png`。用户第 1、4 张参考相同，只生成一组开心图集。

提示词要点（内置工具模式）：保留同一棕色卷发、大眼睛、淡蓝熊图案连体衣、米白熊拖鞋的 3D 萌娃；透明背景；清除彩色边缘；按 3 列 × 2 行分隔六个完整姿势；固定头部比例、镜头、光线和脚底锚点；开心图集依次挥手、拍手、跳跃、抱抱、惊讶、欢呼；爬行图集按手部抬起/前伸/落地排列；睡眠图集依次哈欠、揉眼、点头、双手托腮闭眼、呼吸变化、放松微笑。实际裁切区域通过透明 alpha 边界测量，渲染时统一缩放，不逐帧拉伸。

新增图集由内置图像工具生成，提示词要点：保留参考中的同一 3D 萌娃、服饰、比例和光线；1536×1024 透明背景，6列4行共24个完整姿势；按挥手、手臂缓慢收回、胸前拍手、屈膝、小跳、落地、重新挥手顺序，小幅改变相邻姿势；固定相机、头部比例、脚底基线，不要不同角度、裁切、文字、网格、背景或重叠人物。为避免少数不连续段，播放时把挥手与拍手跳跃分开。

## 流畅版实现与边界

- `SPRITE_SAMPLE_FPS = 120`：按 120 FPS 对连续时间采样，不是把 6 张图重复播放来充数。开心每轮 288 个采样，挥手 192 个，爬行 106 个，入睡 888 个。
- `spriteTweenRenderer.ts`：使用双向稠密光流反向变形与透明度合成，在相邻姿势之间生成新的中间画面；缓存 GPU 程序、图像及运动纹理，不在每帧解码图片或触发 React 重渲染。
- `PetSprite.tsx`：用 `requestAnimationFrame` 替代 50ms 定时器，按屏幕刷新绘制。120 FPS 是采样密度，实际显示受屏幕刷新率、浏览器和设备性能限制，60Hz 屏幕最多显示约60FPS。
- `scripts/build-pet-motion.py`：离线计算数字运动场并生成 `public/pet/motion/*.flow`；不修改原 PNG。仅开发时需要 OpenCV / NumPy，网站没有新增运行依赖，也不调用外部 AI/API。生成时使用本地 Python 工具环境，主项目依赖未更改。
- 暂停、隐藏、弹窗遮盖、离开可见区域和后台标签页会停止播放；减少动态效果时显示稳定姿势。WebGL 不可用/上下文丢失或运动数据不可用时退回 2D 平滑混合；图集失败则使用原站立图。
- 中间帧是计算补间，不是新增实拍视频帧或真实骨骼动画；闭眼、手部遮挡处可能仍有少量混合痕迹，不能等同于原生高帧率3D渲染视频。

未来 GLB 渲染器实现 `PetCharacterProps`（`state`、`direction`），传入 `<WebPet renderer={BabyModel} />`，保留外层状态机、移动、游戏和菜单；在渲染器内部按状态驱动 GLTF clips、头部和眼睛骨骼。当前未加载 Three.js，也不自动假设 GLB 已存在。
