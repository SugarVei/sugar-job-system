房间模型使用本地生成的木纹、织物和墙面纹理。此目录不包含原参考预览里的附属小房子、铺地、长椅或树木街景。

街区使用简化模型和按行合批；打开房间后切换至独立小屋视图，加载圆角家具、窗洞、材质与集中阴影。桌面高清模式在近景启用 GTAO、轻量泛光与 SMAA，手机及流畅模式保留直接光照和阴影。静止的小屋停止绘制，返回街区恢复原设施动画与人物同步。

四种房间风格、家具位置、旋转及颜色通过现有 `community_rooms.data` 保存；`designVersion: 2` 区分用户清空家具与旧版固定书桌。旧书桌迁移为可删除的家具，不新增数据库表或改变所有权策略。家具目录包含 20 个新模型及原有画架，最多 40 件；添加和移动使用旋转后的占地范围，地毯允许放在其他家具下方。

使用 `npm test` 验证旧存档迁移、空房间、完整家具列表、异常数据和摆放规则。`town-preview.html` 是开发环境下沿用真实组件的本地入口，不进入生产构建；正式入口仍是 `/#/community-world/explore`。
